## [css-navigation-1] A pseudo-class for the navigation-initiating element ([#11801](https://github.com/w3c/csswg-drafts/issues/11801))

To support cross-document view transitions, authors want to style the element that started an
outgoing navigation. The group agreed to add a `:nav-source` pseudo-class, and that it applies to
any navigation initiator, not only `<a>` links.

> RESOLVED: Applies not just to links

> RESOLVED: add :nav-source pseudo for this use case

([resolution](https://github.com/w3c/csswg-drafts/issues/11801#issuecomment-4857772799))

## [web-animations] When are `rangeStart`/`rangeEnd` evaluated? ([#13853](https://github.com/w3c/csswg-drafts/issues/13853))

The `Animation` interface's range attributes can hold values that need an element to resolve
(e.g. named timeline ranges). The group made it a parse error to set string or typed-OM values
that require an element to resolve, avoiding an ill-defined evaluation time.

> RESOLVED: make it a parse error to set string values or typed CSSOM values that require an element to resolve

([resolution](https://github.com/w3c/csswg-drafts/issues/13853#issuecomment-4857950246))

## [css-view-transitions][cssom] Inheritance of non-existing pseudo-elements ([#13904](https://github.com/w3c/csswg-drafts/issues/13904))

What `getComputedStyle` returns for a pseudo-element that does not currently exist. The group
resolved such pseudo-elements inherit from their ultimate originating element when queried.

> RESOLVED: non existing pseudo-elements are considered to inherit from their ultimate originating element if you query the computed style

([resolution](https://github.com/w3c/csswg-drafts/issues/13904#issuecomment-4858013386))

## [css-anchor-position-1] `flip-self-inline`/`flip-self-block` keywords ([#14062](https://github.com/w3c/csswg-drafts/issues/14062))

New `position-try` fallback keywords that flip an element around its *own* axis (as opposed to
flipping across the anchor). The group added them and adopted them as the fallback set for the
customizable `<select>` picker. Related: [anchor positioning](../../features/anchor-positioning.md).

> RESOLVED: Use these values for ::picker(select)

> RESOLVED: add flip-self-inline and flip-self-block to position-try

([resolution](https://github.com/w3c/csswg-drafts/issues/14062#issuecomment-4857805306))
