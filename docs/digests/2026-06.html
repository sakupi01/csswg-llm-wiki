This month in CSSWG

June's throughline was implementations catching up to specs, and specs reacting. CSS Color moved toward Candidate Recommendation and immediately drew a wave of byte-exact serialization questions; scroll-driven animations got a batch of timing fixes; and the month's sharpest moment was the Working Group reversing its own resolution on how ::interest-button should turn on. 28 resolutions landed across ~92 active agenda items.

Themes

::interest-button reverses course on turning itself on

The month's most instructive arc. ::interest-button is the pseudo-element that surfaces an affordance for interest invokers (interestfor). Early in June the WG resolved to gate it behind an inline media condition — use display: if(media()) to enable it on the right systems. lwarlow argued UAs should keep latitude ("the spec should give UAs the freedom to enable or disable it") and that fears of layout breakage were unrealistic. Weeks later the group voided that resolution: LeaVerou, after developer conversations at CSS Day, reported authors would simply turn it off — anything that affects layout by default breaks pages, and an opt-out adds more UX noise (stray tab stops, tooltips intermixed with real targets) than it solves. Net: whether and how ::interest-button is on by default is open again (#13980, 37 comments this month). The tension — UA latitude vs. "layout-affecting defaults will be disabled" — is the one to watch as interest invokers ship.

Scroll-driven animations get a semantics pass

A cluster of precision fixes for scroll/view timelines, individually small but together removing a batch of "why did my scroll animation jump?" foot-guns: timeline-source changes now apply asynchronously; auto-rewind has no effect when the timeline is unresolved, paired with a new play-always trigger that always rewinds; startOffset/endOffset became nullable; and scroll-timeline names are now loosely matched.

CSS Color 5: shipping forces the exact answers (still contested)

Color 4 advanced to CRD and Color 5 was republished as a WD mid-month, and the practical consequence was a burst of "what exactly serializes?" threads — most still open. How color-mix() parses and whether the sum-to-zero tests move rather than delete (#13996); the resolved value and serialization of alpha() in relative color (#13994); and whether alpha is omissible in relative-color serialization — sent to async with svgeesus noting "we don't have consensus" (#14070). Example 32 was flagged as outdated against the newer none/powerless-component model (#14100, 19 comments). In parallel, Color 4's static gamut-mapping algorithm is now being implemented (Firefox) and benchmarked (#10579). The pattern: with engines shipping, the group is pinning down behavior that used to be "close enough."

New surfaces reach milestones

Link Params was published as a First Public Working Draft (#14028), with its param() function required to carry at least two values. Randomness matured in Values 5 — resolutions on how random() evaluates inside arbitrary substitution and on sibling-index()/sibling-count() failure behavior, while random-item() weighting wrestled with a syntax overlap (block 20% is ambiguous) and leaned toward an if()-like pattern. And forms/anchor-positioning groundwork landed: the <select> position-try fallbacks were redefined and @position-try gained globally-scoped names like @keyframes — the runway for July's flip-self-* keywords.

Resolutions this month

Highlights of the 28 resolutions, grouped:

  • Scroll/animation timing — #13480, #13817, #13643, #13844, #13818, #13974.
  • Values & randomness — #13662, #13736, #9720 serialization of functional notation.
  • Forms & anchor positioning — #13541, #13567, #13765 inset keyword for outline-offset.
  • Publishing — Link Params FPWD (#14028), republish Gaps L1 (#6900).
  • Author-facing tweaks — zoom: normal computes to 1 (#10270), no limit on meta text-scale (#13557), caption-side gets block-start/block-end (#9623), <an+b> renamed <a-n-plus-b> (#9473).

Still contested

  • CSS Color 5 serialization cluster: #14100, #13996, #13994, #14070 (alpha omissibility, no consensus).
  • Static gamut-mapping algorithm (#10579) — implementation results diverging.
  • random-item() weighting syntax (#14079).
  • Masonry reading-order / accessibility (#5675) — the long-running objection, part of the CSS Masonry story.
