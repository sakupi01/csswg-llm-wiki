This week in CSSWG

One telecon (2026-07-01) produced six resolutions. The through-line was form-and-navigation ergonomics: anchor positioning grew self-flipping keywords and gained a home for the <select> picker, and a new pseudo-class was minted to style the element a navigation came from. The week's loudest threads were in CSS Color 5 and, again, Masonry.

Notable

  • Anchor positioning learns to flip itself, and anchors the select picker (#14062). Two resolutions landed on this issue: to add flip-self-inline and flip-self-block to position-try, and to use these values for ::picker(select). The self-flipping keywords let a positioned element flip across its own box rather than only relative to its anchor — filling a gap authors hit when a fallback should mirror the element in place. Tying them to ::picker(select) connects anchor positioning to the customizable <select> work, one of the most-watched author-facing surfaces right now.
  • A :nav-source pseudo-class for the element a navigation left from (#11801). The WG resolved that the feature applies not just to links and to add a :nav-source pseudo for this use case. This gives cross-document view-transition and scroll-restoration styling a way to target "where the user came from," not only anchor elements — a small selector with outsized relevance to multi-page app transitions.
  • View Transitions: what getComputedStyle returns for a pseudo-element that doesn't exist (#13904). Resolved that non-existing pseudo-elements are considered to inherit from their ultimate originating element when you query the computed style. A CSSOM-correctness call, but one that pins down observable behavior for tools and tests probing view-transition pseudo trees.
  • Web Animations tightens typed-value setting (#13853). Resolved to make it a parse error to set string values or typed CSSOM values that require an element to resolve. Closing a footgun where a value that can only be resolved against a live element was silently accepted.

Loud this week (no resolution yet)

  • #14100 css-color-5: Example 32 is outdated — 22 comments.
  • #5675 Masonry reading-order / accessibility — 17 comments; the long-running accessibility objection to Grid-integrated masonry, part of the CSS Masonry story.
  • #14088 css-color-5: calc(infinity) in relative color and interpolation — 10 comments.

Also resolved

  • #11801 — the navigation feature applies beyond links (paired with the :nav-source resolution above).
